# South Africa Highlights

A small static two-page site on the best places to visit in South Africa, built by the Orchestrate Solutions team.

## Pages
- `index.html`: home page, overview of the country and why visit
- `pages/places.html`: the best places to visit

## Layout
- `css/tokens.css` (Designer), `css/layout.css` (UI/UX), `css/site.css` (Lead Dev)
- `js/app.js` (Full-Stack), `js/nav.js` (UI/UX)
- `assets/`: original SVG illustrations

Plain HTML, CSS and JavaScript. No build step.
